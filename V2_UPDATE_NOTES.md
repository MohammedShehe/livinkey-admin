# V2 update – admin panel

- **Dashboard**: PG filter (pills / dropdown) + period filter, 8 KPI cards, billed/collected/expenses chart, bill-status donut, occupancy, attention list, PG comparison table (All PGs), tenant mix, highest dues, expense categories. The chosen PG is remembered.
- **Expenses** (new page + menu item): add/edit/delete, receipt upload, filters (PG, period, category, search), stat cards, 12-month money in vs out, category donut, spending by PG, top expenses, CSV export.
- **PGs → gift button**: manage offers, switch on/off, schedule dates, coupon code, notify guests.
- **PGs → bolt button (Super Admin)**: electricity formula per PG (flat or slabs, fixed charge, minimum, multiplier, tax) with live calculator and "copy to other PGs".
- **Bills → Create**: choose "From meter readings"; previous reading is pre-filled from the last bill; the amount is calculated automatically.
- **Documents**: review status filter, NEW badge, upload time, approve / reject (with reason), bulk approve/reject, review panel in preview.
- **Add tenant → Auto-fill**: attach several photos/PDFs at once or one after another; each fills only the fields still empty; shows which fields remain.
- Admin permissions list now includes **Expenses**.
